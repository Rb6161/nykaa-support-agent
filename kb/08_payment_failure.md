# Payment-failure and retry policy

If a payment fails but money is debited, the amount is automatically reversed to the source within 5 to 7 working days. The customer may retry the payment up to 3 times from the same cart before the order is released. Using a different method such as UPI, card or net banking often resolves gateway issues. An order is created only after a payment succeeds, so a failed payment does not produce an order ID.
